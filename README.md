# comunidade-conectada-mvp
MVP para registro e acompanhamento de ocorrências comunitárias no bairro Santo Antônio, Sarzedo-MG.

## Sobre o projeto

O Comunidade Conectada é um sistema web desenvolvido para facilitar a comunicação e a participação dos moradores do bairro Santo Antônio, localizado em Sarzedo, Minas Gerais.

## Objetivo

Permitir que os moradores registrem problemas identificados na comunidade e acompanhem o andamento das solicitações.

## Funcionalidades previstas

- Cadastro de ocorrências.
- Registro de categoria, descrição e localização.
- Consulta das ocorrências registradas.
- Acompanhamento do status das solicitações.
- Gerenciamento das ocorrências pela administração.

## Tecnologias utilizadas

- Python 3
- Flask
- HTML5
- CSS3
- SQLite (previsto para persistência dos dados).

## Execução local

1. Crie e ative o ambiente virtual.
2. Instale as dependências:

   pip install -r requirements.txt

3. Execute a aplicação:

   python run.py

4. Acesse no navegador:

   http://127.0.0.1:5000
